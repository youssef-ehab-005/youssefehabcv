# Youssef Ehab — Personal Portfolio

A bilingual (English/Arabic), dark multi-page personal portfolio starter.

## Pages
- `index.html` — Home
- `about.html` — About
- `skills.html` — Skills
- `education.html` — Education
- `experience.html` — Training & experience
- `projects.html` — Projects
- `certs.html` — Courses & certificates
- `contact.html` — Contact
- `admin.html` — Local demo content manager

## Run locally
Open `index.html` in a browser, or run a local static server from this folder:
`python3 -m http.server 8000`
Then visit `http://localhost:8000`.

## Before publishing
1. Replace the portrait placeholder with your approved professional photo.
2. Add your real email, LinkedIn, GitHub and other public contact links.
3. Upload your latest CV as `assets/Youssef_Ehab_CV.pdf`.
4. Verify dates, project descriptions, certificates and training details.
5. The admin page is a front-end demo using browser localStorage only. It has NO secure login and does not sync across devices. Do not expose it publicly as a real admin panel. For production, add authentication, role-based authorization, server-side validation, database storage and protected API routes (for example Next.js + Node.js + PostgreSQL).
6. Connect the contact form to a backend or a trusted form service if you want messages delivered without opening the visitor's email app.
